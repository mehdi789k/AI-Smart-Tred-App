# اندیکاتورها

هر اندیکاتور در یک فایل پایتون مستقل قرار دارد و پارامترهای قابل تنظیم آن در ابتدای همان فایل تعریف شده است.

فایل‌ها:

- `rsi.py`: شاخص قدرت نسبی
- `volume.py`: حجم، میانگین حجم و نسبت حجم
- `moving_average.py`: میانگین متحرک ساده و نمایی
- `market_regime.py`: تشخیص رژیم روند/نوسان بازار
- `macd.py`: مکدی
- `bollinger_bands.py`: باندهای بولینگر
- `stochastic.py`: استوکاستیک
- `atr.py`: میانگین دامنه واقعی
- `adx.py`: شاخص قدرت روند

اجرای هر فایل با مسیر یک فایل دادهٔ بازار:

```powershell
python indicators\rsi.py market_data\GBPUSD_l_H1_20260904_07.json
```

خروجی JSON شامل کندل‌های ورودی و مقدار اندیکاتور مربوط است. برای تغییر رفتار، ثابت‌های ابتدای فایل یا آرگومان‌های توابع `calculate_*` را ویرایش کنید.
